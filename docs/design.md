# 产品设计

## 设计目标

让玩家能够清楚看到“已有数据、刚识别的数据和待确认的数据”，以从者卡片和队伍槽位完成主要操作。视觉风格已确定为朴素、现代、简洁美观。游戏体验主要通过头像、立绘和编队槽位体现，整体采用克制的桌面工具布局。具体主题、组件库和页面规划见 [界面设计方案](ui-design.md)。

## 信息架构

| 页面 | 内容与操作 |
| --- | --- |
| 设备与采集 | 选择设备、连接状态、截图预览、采集任务进度、取消、识别与校对 |
| 从者库 | 头像卡片、名称、职阶、等级；按名称/职阶/培养状态筛选，进入详情 |
| 从者详情 | 等级、宝具、再临、技能；来源、更新时间、校对状态与素材选择 |
| 礼装管理 | 概念礼装持有实例、等级、突破状态；御主礼装拥有状态与等级；手工录入/修正 |
| 编队 | 六槽位与概念礼装编辑、助战选择、御主礼装选择、COST 明细、保存/复制、关卡关联 |
| 战斗助手 | 当前截图、状态摘要、建议步骤、依据、未知项、重新分析 |
| 设置 | ADB 路径、模型适配器、数据位置、区服/语言和设备布局配置 |

## 从者采集流程

1. 玩家选择设备和账号档案，打开游戏中的从者页面。
2. 工具抓取截图并标注采集时间、设备及页面类型。
3. 识别身份与字段，头像/立绘裁剪作为素材候选。
4. 详情页可能分散在多个页面，按采集会话形成候选档案；跨页必须校验身份一致。
5. 校对面板逐字段展示原值、候选值、置信度、来源截图裁剪。
6. 玩家选择“新增持有实例”或“更新已有实例”，确认后事务保存。
7. 保存结果显示已更新字段；重复采集、取消或失败不能产生无来源的半成品档案。

首版已确认手动切页后识别，界面显示本次已采集页和缺失字段。自动翻页若成本低可增加开关，默认手动；沿用同一候选与校对流程，失败时回到手动继续。

## 素材流程

头像与立绘全部从游戏截图裁剪，生成缩略图并按内容哈希去重。保留截图来源、裁剪区域与用户确认的持有实例关联，不匹配官方外观编号。只保留画面可见部分；支持重新采集、预览、裁剪和替换，缺图用占位。按头像和立绘用途分别保存，不使用官方图片补图。

名字识别后展示原文、截图和官方中／日名称候选，支持重识别、手动编辑检索、选择条目或保留未知。同名多条不自动选定，重复持有不按名字合并。详情页分别提供名称校准、培养字段重识别、头像/立绘重采集入口，新旧差异确认后保存，取消保留原数据。更换素材不改写培养字段；改绑名称身份时提示关联编队并将旧培养数据标记待复核。修正可撤销，具体流程见 [名称校准与识别评估](recognition-evaluation.md)。

## 编队流程

建立空队伍 → 从从者库选取实例/配置助战 → 配置各槽位概念礼装 → 选择御主礼装 → 调整顺序 → 查看 COST 校验 → 可选关联关卡 → 保存。拖拽和点击选择都可用。

普通队伍显示前排与后备；助战配置独立标记。队伍草稿允许空槽位。概念礼装、御主礼装、助战和 COST 校验已确认纳入首版。校验状态区分通过、超限、信息不足；队伍未填完整和特殊关卡限制另行提示，COST 通过不等于可出战。超限或信息不足仍可保存草稿。保存仅表示本地持久化，不表示游戏内编队已同步。

## 战斗助手流程

主动截图 → 确认处于支持的战斗页面 → 提取可观察状态 → 生成建议 → 展示依据与不确定项。建议绑定截图编号和时间，切回合、设备断连或状态改变后提示重新分析。

战况候选字段包括回合、波次、敌人血量/职阶、己方 HP/NP、可见技能状态和指令卡。截图不可见的技能效果、敌人机制和隐藏状态需由确认的静态数据或历史事件补充，缺失时保持未知。

首版已确认仅提供建议，玩家在 MuMu 中手动操作。界面不提供战斗执行按钮。自动翻页仅作为采集流程的可选增强，不扩展到战斗操作。

## 异常与反馈

- 无设备或 ADB 未授权：显示原因和重新检测入口。
- 多设备：明确显示当前设备，每个任务绑定固定设备序列号。
- 未识别页面或分辨率不支持：保留截图，允许重试或手动录入。
- 低置信度：突出待校对字段，不能将推测表现为确定结果。
- Agent 超时或离线：保留状态摘要，允许重试，其他本地管理功能继续可用。
- 素材丢失：占位图与重新采集入口。
- 任务取消：停止后续步骤，保留已确认数据，候选不自动提交。

## 礼装、助战与 COST 细节

- 概念礼装按持有实例选择，展示等级、突破状态和费用；同名多份可独立配置，同一实例不可重复占位。首版建议先支持手工录入，识别采集范围另行细化。
- 御主礼装属于整支队伍，显示名称、等级和技能资料；不占从者槽位。
- 助战可保存期望条件（从者、培养要求、礼装与满破要求）或当前观察到的具体配置；两者清楚区分，期望条件不代表游戏中已经找到对应助战。
- 常规 COST 为自有从者与其装备概念礼装费用之和；助战从者及其礼装不计入，御主礼装不计入。特殊关卡规则覆盖常规规则，并显示规则来源。
- 首版上限从游戏可见信息识别或手工输入并记录来源；等级映射表待规则资料来源确定后再加入。任一必要费用、上限或规则未知时显示“信息不足”，不得判定通过。
